# Mezgeb SMS library
19 events, 57 localized messages in catalog.json. All entries disabled by default. {code} is a source placeholder, not a Supabase template variable. Native SMS uses {{ .Code }} (verify dashboard before activation); a custom hook receives sms.otp and user data from authenticated Supabase request. The auth category does not imply all listed OTP purposes are available in this project's settings. Use generic verification copy unless event purpose is trusted. Security/optional categories require a separate server-owned event pipeline and consent; no provider, send endpoint or event pipeline is enabled. See MASTER_PROMPT.md for implementation and acceptance gates. No credentials or actual phone numbers in repository.
