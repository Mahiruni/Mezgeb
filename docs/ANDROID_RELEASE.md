# Mezgeb 1.0.0 release candidate

Version code 7, unchanged package and origin. Release variant is non-debuggable, bundles the entire existing Signature interface, checks assets and cloud public configuration, and has an optional fail-closed production signing stage. Configure the owner-held Mezgeb key in repository Actions secrets MEZGEB_ANDROID_KEYSTORE_BASE64, MEZGEB_ANDROID_KEYSTORE_PASSWORD, MEZGEB_ANDROID_KEY_ALIAS, MEZGEB_ANDROID_KEY_PASSWORD, and repository variable MEZGEB_ANDROID_CERT_SHA256. Never commit a private key or password. A signing certificate pin must match the intended existing installed package for in-place upgrade. No key or pin is generated automatically. Unsigned release candidate is not installable; no native-update manifest is enabled until signed distribution and upgrade verification. Existing preview APK was signed by Android Debug, SHA-256 8092247b9ab468adeca99cd47eb57a5a27a9d2e313a03005b131790c849fdda7; this does not establish the user's installed certificate or access to its private key. Production signing, authentic human recordings, native translation review and device verification remain gates.
