# Android-first bundled Signature preview 0.4.1

The APK includes the React ledger interface, compiled CSS and local fonts. A read-only versioned path under the exact existing HTTPS origin serves signed package assets from Android's WebView request interceptors. IndexedDB and localStorage stay in their existing origin; no migration or storage wipe is introduced. Backend routes remain network requests. Existing service workers are not deleted. Public Supabase configuration is used only if a verified publishable/anon key is available; otherwise the local ledger works and the existing online account/cloud UI remains explicitly accessible. Android confirmation and package signature continuity still require a real installed-device upgrade test. Debug artifact is not production-signed. Never uninstall to force this update.
